# YOLOv8 Object Detection Training & Analysis Suite

**고급 물체 감지 모델 학습, 평가, 분석을 위한 PyQt5 기반 통합 GUI 애플리케이션**

---

## 🎯 프로젝트 소개

이 프로젝트는 **YOLOv8 기반 물체 감지(Object Detection) 모델**의 전체 라이프사이클을 관리하는 통합 도구입니다. 데이터 라벨링부터 전처리, K-Fold 학습, AutoML, 평가, 그리고 객체 간 거리 측정 및 통계 분석까지 하나의 프로그램에서 모두 수행할 수 있도록 설계되었습니다.

### 핵심 목표

* ✅ **데이터 라벨링 및 전처리 자동화**
* ✅ **모델 학습** (K-Fold 교차 검증, Optuna 기반 AutoML)
* ✅ **모델 평가 및 오답 선별**
* ✅ **객체 간 거리 측정 및 통계 분석**
* ✅ **오답 중심 하드 엑자플(Hard Example) 재학습**
* ✅ **Discord 실시간 비동기 알림 통합**
* ✅ **SQLite 기반 모든 작업 로깅 및 히스토리 관리**

### 대상 사용자

* 품질 검사(QC) 자동화 시스템 개발자
* 물체 감지 딥러닝 모델 연구자
* 산업용 비전 시스템 개발자

---

## ⭐ 주요 기능

### 1️⃣ **이미지 라벨링 툴 (Tab 6)**

* OpenCV 템플릿 매칭 기반 유사 객체 자동 라벨링 (Auto Labeling)
* 단축키(Q/E, S/W 등)를 통한 초고속 수동 라벨링 지원
* NMS(Non-Maximum Suppression)를 통한 중복 박스 자동 제거

### 2️⃣ **데이터 전처리 (Tab 1)**

* YAML 기반 이미지 경로 자동 파싱 및 BBox 좌표 정규화
* 불필요한 메타데이터 및 EXIF 회전 정보 보정/제거
* 여백 설정이 가능한 객체 중심 자동 크롭(Auto Crop)

### 3️⃣ **모델 학습 (Tab 2)**

* **K-Fold 교차 검증** (단일 분할 및 1~10 Fold 지원)
* **AutoML 기능**: Optuna 기반 하이퍼파라미터(학습률, 손실함수, 증강 등) 자동 최적화
* 학습 곡선 실시간 모니터링 및 Early Stopping 지원

### 4️⃣ **모델 평가 및 선별 (Tab 3)**

* 학습된 모델을 이용한 일괄 검증 및 정답/오답(과검, 미검) 자동 분류
* 신뢰도 및 IoU 기반 평가, 완벽 일치율 및 F1-Score 계산
* 오답 이미지만 별도 폴더로 자동 추출 (재학습용)

### 5️⃣ **재학습 (Tab 4)**

* Tab 3에서 선별된 오답(Hard Example) 데이터 중심의 전이 학습
* 재학습 완료 후 자동으로 최종 성능 평가 진행 및 검출 지표 제공

### 6️⃣ **거리 측정 & 통계 분석 (Tab 5)**

* **3가지 거리 측정 방법**:
* 테두리 최단거리 (Edge)
* 중심점 유클리드 (Center)
* 가장 가까운 N개 이웃 (방향 무관)


* KDE Plot, Boxen Plot 등을 통한 분포 시각화 및 이상치(Outlier) 자동 검출
* 측정 결과 및 통계 데이터 CSV 내보내기

### 7️⃣ **설정 관리 및 히스토리**

* JSON 기반 설정 저장/불러오기 (손상 시 기본값으로 자동 복구 기능 포함)
* SQLite 기반 영구 로깅 (학습, 평가, 튜닝 세대별 이력)
* 이전 설정과의 차이점(Diff) 비교 UI 제공

### 8️⃣ **Discord 실시간 알림**

* 작업 시작/완료, 폴드 종료, 조기 종료 시 알림
* 오류 발생 및 UI 프로세스 치명적 충돌 시 유언(Fallback) 메시지 전송
* 웹훅 기반 완전 비동기 처리로 GUI 응답성 보장

## 🔧 주요 기술 구현

### 1. **멀티프로세싱 및 VRAM 격리 아키텍처**

* 메인 UI 스레드(Qt)와 워커 스레드(QThread)를 분리하고, 실제 YOLO 연산은 완전히 격리된 별도의 Process(`multiprocessing.Process`)에서 실행합니다.
* 작업 완료 또는 취소 시 프로세스 트리를 정리하고 `torch.cuda.empty_cache()`를 호출하여 **VRAM 누수를 원천 차단**합니다.
* 진행 상황은 Non-blocking Queue를 통해 UI로 안전하게 전달됩니다.

### 2. **안전 종료 (Graceful Stop)**

* 사용자의 종료 요청 시 워커 프로세스에 중단 플래그를 전달하여 에포크가 끝날 때 안전하게 종료(Graceful shutdown)되도록 유도합니다.
* 중단 시점까지의 결과물(CSV, 모델 가중치 등)을 디스크에 안전하게 보존합니다.

### 3. **SQLite 데이터베이스 구조**

* 단일 연결 지점을 가진 백그라운드 DB Writer 쓰레드를 활용하여 로깅 충돌을 방지합니다.
* `training_logs`: K-Fold 및 모델 학습 이력 (Best mAP, 설정 파라미터 등)
* `evaluation_logs`: 평가 결과 이력 (총 이미지, 오답 수, 정확도, 오답 이미지 목록 등)
* `tune_logs`: AutoML(Optuna) 탐색 세대별 하이퍼파라미터 및 Fitness 점수 이력

### 4. **통합 로깅 시스템**

* `logs/app.log` 단일 파일에 `RotatingFileHandler`를 적용하여 기록합니다. (최대 10MB, 백업 5개 유지)
* EmojiFormatter를 적용하여 콘솔 가독성을 높였습니다.

## ⚠️ 주의사항

### 1. 권장 폴더 구조

프로그램 실행 시 지정한 '프로젝트 루트' 하위에 다음과 같은 구조가 자동 생성됩니다.

```text
프로젝트 루트/
├── dataset/                    # 원본 이미지 및 라벨 파일 (.txt 또는 .json)
├── processed_dataset/          # Tab 1 전처리 완료 및 Tab 6 라벨링 대상 데이터
└── workspace/
    ├── configs/                # 저장된 UI 설정 백업 파일 (.json)
    ├── kfold/                  # K-Fold 분할 데이터 및 베이스 모델 (best_model.pt)
    └── runs/                   # 작업 결과물이 저장되는 메인 디렉토리
        ├── eval/               # 모델 평가 및 오답 시각화 결과
        ├── measure/            # 거리 측정 결과 이미지 및 CSV 통계 자료
        ├── retrain_train/      # 하드 재학습 진행 이력 및 모델
        └── tune_custom/        # AutoML 튜닝 과정 및 히스토리(CSV/DB)

```

### 2. K-Fold 데이터 관리

* K-Fold 설정 시 분할된 데이터는 `workspace/kfold/` 하위에 각 폴드별로 자동 구성됩니다.
* 최적의 성능을 낸 베이스 모델(`best_model.pt`)은 해당 폴더에 자동으로 복사되므로, 이후 평가나 재학습 시 해당 가중치를 사용하면 됩니다.

### 3. GPU/메모리 관리 (OOM 해결)

* `CUDA out of memory` 발생 시 다음 조치를 취하세요.
1. Tab 2에서 `Batch Size` 감소 (예: 16 → 8)
2. 전역 설정에서 `imgsz` 감소 (예: 640 → 416)
3. `Workers` 설정 조정 (Windows의 경우 0~4 권장)



### 4. Discord 웹훅 보안

* 디스코드 웹훅 연동 시 입력한 URL은 로컬 PC의 레지스트리(또는 설정 파일)에 저장됩니다. URL이 깃허브나 외부로 유출되지 않도록 주의하세요.
